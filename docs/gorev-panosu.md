# GitHub Projects görevleri

Sütunlar: **Yapılacak**, **Devam Ediyor**, **Tamamlandı**.
Bu dosya canlı pano değildir. GitHub Projects'te kartlar ayrıca oluşturulmalıdır.

## 1. Gezi oluşturma
Kullanıcı gezi adı, şehir, başlangıç ve bitiş tarihlerini girerek gezi oluşturur.
- [ ] Geçerli bilgilerle kaydedilen gezi listede görünür.
- [ ] Bitiş başlangıçtan önceyse kayıt engellenir.
- [ ] Sayfa yenilendiğinde gezi korunur.
Doğrulama: README'deki Özellik 1 adımları.
Commit/PR: GitHub'a aktarıldıktan sonra gerçek bağlantı eklenecek.

## 2. Günlük plana durak ekleme
Kullanıcı gezi gününü seçer, yer adı, saat ve isteğe bağlı not ekler.
- [ ] Durak yalnızca seçilen günün planında görünür.
- [ ] Aynı günün durakları saate göre sıralanır.
- [ ] Sayfa yenilendiğinde duraklar korunur.
Doğrulama: README'deki Özellik 2 adımları.
Commit/PR: GitHub'a aktarıldıktan sonra gerçek bağlantı eklenecek.

## 3. Durak düzenleme ve silme
Kullanıcı mevcut durağını düzenler veya siler.
- [ ] Kaydedilen düzenleme listede ve sayfa yenilendikten sonra görünür.
- [ ] Kullanıcının silme onayından sonra durak kaldırılır.

## 4. Tahmini bütçe hesaplama
Kullanıcı ulaşım, konaklama ve yemek giderlerini girer.
- [ ] 1000 TL ulaşım, 2000 TL konaklama ve 500 TL yemek için 3500 TL toplam gösterilir.
- [ ] Negatif gider kabul edilmez.

## 5. Gezi planını PDF indirme
Kullanıcı gezi planını dosya olarak indirir.
- [ ] PDF gezi adını, şehri, tarihleri ve günlük durakları içerir.
- [ ] Türkçe karakterler doğru görünür.

## Durumların kullanımı
Bir göreve başlarken Devam Ediyor'a taşı. Gerçek commit/PR bağlantısını karta ekle.
Kabul kriterlerini uygulamada denedikten sonra işaretle ve Tamamlandı'ya taşı.
Önceden gerçekleşmemiş pano hareketleri veya testler gerçekleşmiş gibi kaydedilmemelidir.
